厨房更新于2026-11-09：柜门、吊柜和转角前车只留竖向骨骼线；抽屉保留上方和中间横条，全部最底横条取消。木柜踢脚补完整，从平板门面内退30mm，转角L形踢脚先拆再拉车。烟机遮挡、左端收口修正保留。

厨房页面为单文件HTML，内含Three.js、样式、模型与交互，无后端和外部脚本依赖。手机浏览器可直接访问，支持旋转、开门、抽屉、转角推车、尺寸调整和打印。新增“左排＋中间”和“右排＋中间”，保留水槽和对应转角、隐藏另一侧长排；可保存当前画面PNG。三维显示需要浏览器支持WebGL；页面提供静态图回退。

[左排＋中间图片](kitchen-u/left-middle.png) · [右排＋中间图片](kitchen-u/right-middle.png)

由GitHub Pages从main分支根目录发布。厨房的最新柜体方案在独立页面，全屋场景的柜体未同步改造。

页面临时调参不会改写仓库默认尺寸。模型中的烟机隐藏机身与五金仍是空间占位，实际安装按设备型号及现场复核。
