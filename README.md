# 全屋与厨房3D

- [全屋空间](https://llinvokerl.github.io/home-3d-viewer/)
- [厨房U型柜 · A06修订1](https://llinvokerl.github.io/home-3d-viewer/kitchen-u/)

厨房更新于2026-11-09：吊柜仅竖向骨骼线；地柜上下横线同高；烟机上方柜门与两侧齐底，只露出烟机下部；取消左端多出的收口和台面。

厨房页面为单文件HTML，内含Three.js、样式、模型与交互，无后端和外部脚本依赖。手机浏览器可直接访问，支持旋转、开门、抽屉、转角推车、尺寸调整和打印。三维显示需要浏览器支持WebGL；页面提供静态图回退。

由GitHub Pages从main分支根目录发布。厨房的最新柜体方案在独立页面，全屋场景的柜体未同步改造。

页面临时调参不会改写仓库默认尺寸。模型中的烟机隐藏机身与五金仍是空间占位，实际安装按设备型号及现场复核。
